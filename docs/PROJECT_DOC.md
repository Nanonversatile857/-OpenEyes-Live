# 👁️ OpenEyes-Live — 项目文档

> **一个模块化、可插拔、端云协同的端侧多模态AI基础设施。**  
> —— 把最新的端侧AI模型，变成可独立下载、按需加载、自由组合的智能引擎。

**文档版本:** v0.1.0
**更新日期:** 2026-07-25
**适用版本:** OpenEyes-Live v0.1.x

---

## 📖 项目概述

### 🎯 愿景

**让每一台带摄像头的旧设备，都能拥有「看懂、听懂、辨人」的完整智能。**

OpenEyes-Live 是一个开源的、完全本地的端侧多模态AI基础设施。它通过**视频引擎流水线（帧采样→帧筛选→视觉编码→Token压缩）** 和 **音频引擎流水线（VAD→ASR→声纹识别）** 的模块化设计，让一台2017年的旧手机在5分钟内变成「看得懂世界、听得懂语言、辨得出身份」的智能设备。

### 💡 使命

通过**模块化引擎 + 按需下载 + 量化压缩 + 端侧分离**的技术路径，把多模态AI能力的门槛从「旗舰手机 + 云端API」降到「任何带摄像头和麦克风的设备」。

### 🧭 核心价值主张

| 价值 | 说明 |
| :--- | :--- |
| 🔪 **视频引擎流水线化** | 4个独立阶段（采样→筛选→编码→压缩），每段可插拔、可替换 |
| 🎤 **音频引擎全模态化** | 3个独立阶段（VAD→ASR→声纹），让AI「听得懂、辨得出」 |
| 🧩 **按需组合** | 10个子引擎独立下载、按需加载，自由组合成任意流水线 |
| 📦 **极致轻量** | 最小基础包可低至80MB（仅VAD引擎），全部加载约700MB |
| 🔒 **完全本地** | 所有数据不出设备，零联网依赖，隐私绝对安全 |
| 🌏 **国内加速** | 通过ModelScope镜像，国内用户也能高速下载 |
| 💰 **永久免费** | 没有API Key，没有订阅，没有隐藏成本 |
| 🔓 **开源透明** | Apache 2.0协议，代码可审计、可修改、可商用 |

## 🧩 功能模块说明

### 视频引擎流水线（4个引擎）

| 引擎 | 模型 | 大小 | 功能 | 输入→输出 |
| :--- | :--- | :--- | :--- | :--- |
| **帧采样引擎** | Configurable | ~5MB | 降低帧率，减少计算量 | 30fps→5-15fps |
| **帧筛选引擎** | Attention Scorer | ~15MB | 自动选出最关键的帧 | 15fps→3-8关键帧 |
| **视觉编码引擎** | VideoMamba/CLIP | ~200MB | 提取视觉特征 | 关键帧→视觉嵌入 |
| **Token压缩引擎** | Token Projector | ~20MB | 压缩冗余Token | 256 Token→64-128 Token |

### 音频引擎流水线（3个引擎）

| 引擎 | 模型 | 大小 | 功能 | 输入→输出 |
| :--- | :--- | :--- | :--- | :--- |
| **VAD引擎** | Silero VAD | ~2MB | 检测是否有人说话 | 音频流→语音片段 |
| **ASR引擎** | SenseVoice int8 | ~234MB | 语音转文字+标点恢复 | 语音→带标点文本 |
| **声纹引擎** | ECAPA-TDNN | ~30MB | 识别说话人身份 | 语音→说话人ID |

### 核心引擎（3个引擎）

| 引擎 | 模型 | 大小 | 功能 |
| :--- | :--- | :--- | :--- |
| **语言推理引擎** | Qwen/Llama | ~400MB | 多模态融合推理，生成自然语言 |
| **记忆引擎** | Sentence-BERT+FAISS | ~50MB | 向量记忆+时间线检索 |
| **MCP网关引擎** | Lightweight Adapter | ~10MB | 暴露能力给AI客户端 |

## 🏗️ 核心设计理念

### 1. 引擎流水线化

> **视频：采样→筛选→编码→压缩，4段独立可插拔。音频：VAD→ASR→声纹，3段独立可插拔。**

传统端到端模型将整个理解过程打包在一个巨大网络中，无法拆分、无法复用、无法优化。OpenEyes-Live将理解和感知拆分为7个子引擎，每个引擎只做一件事，做得最好。

**设计原则：** 每个引擎都可以被替换、升级、或单独使用。

### 2. 按需组合

> **用哪个下哪个，不需要的绝不下载。**

旧设备存储空间有限，一次性下载所有模型不现实。OpenEyes-Live的 `EngineManager` 管理所有引擎的下载、加载、卸载：

- 用户只执行 `openeyes install vad` 时才下载VAD引擎
- 执行 `openeyes watch --engines encoder+llm` 时才加载这两个引擎
- 内存低于阈值时自动卸载不活跃的引擎

**设计原则：** 最小安装包仅80MB，完整安装约700MB。

### 3. 性能优先

> **宁可降低精度，也要保证可用性。**

在旧手机上，推理速度 > 识别精度。OpenEyes-Live的设计原则：

1. 使用Q4_K_M量化（精度损失<5%，体积减少75%）
2. 使用帧筛选（只在关键帧触发推理，计算量减少50-70%）
3. 使用Token压缩（Token数量减少50-75%，推理速度翻倍）
4. 使用VAD门控（只在有人说话时运行ASR，功耗降低90%+）

### 4. 完全本地，零联网

> **数据不出设备，隐私绝对安全。**

OpenEyes-Live所有处理在设备本地完成，没有任何联网依赖。ASR使用 **sherpa-onnx** 直接加载本地ONNX模型，不依赖ModelScope SDK或任何云端服务。

**设计原则：** 断网环境下完全可用。

## 🔐 隐私与安全承诺

| 承诺 | 说明 |
| :--- | :--- |
| **零数据上传** | 所有摄像头画面在本地处理，绝不发送至任何服务器 |
| **零存储** | 不保存任何视频录像，仅在内存中分析当前帧 |
| **零联网依赖** | ASR、VAD、声纹、视觉编码全部本地运行，无需联网 |
| **开源可审计** | 完整源代码公开，安全专家和社区可随时审查 |
| **无后台服务** | 不联网、不注册、不收集任何用户信息 |
| **可自主删除** | 所有数据用户可自行删除 |
